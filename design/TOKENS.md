# Design tokens

Use these as CSS variables or theme values. Do not copy values out of the screen HTML.

## Colour

| Token | Value | Use |
| --- | --- | --- |
| bg | #0A0F2C | Page background (deep space) |
| card | #18204A | Cards, rows, buttons |
| line | #2E3A78 | Borders and dividers |
| track | #5D6CC4 | Progress meter backgrounds and other non-text contrast |
| ink | #F3F4FF | Main text |
| muted | #B9C0EA | Secondary text |
| hi (orange) | #FF9F5A | Main action, "Up next", highlights |
| ink-on-orange | #2A1400 | Text and icons on orange |
| ok (teal) | #5ED6C4 | Done, ready, success |
| amber | #FFD166 | Stars, waiting |
| label | #1E2756 | Labels on the trip path |
| bonus planet | #F2B544 | Daily bonus planet |

Children: Mia #F28AA0, Leo #6EC6F0 (each child's colour appears as the top bar and on their rocket).

Reward planet colours used in the designs: #9C8CF0, #5BB58A, #E0B67A, #6EC6F0, #E58FB8.

## Type

- Headings: Lilita One.
- Body: Nunito, weight 700 to 900.
- Smallest text 13 px. Headings 28 to 44 px.

## Layout

- Phone boards 390 x 844, corner radius 28.
- Touch targets at least 44 px. Rows 56 to 68 px.
- Buttons: orange primary with a darker bottom edge, ghost (card colour with border), danger (red outline), ok (teal).
- Never show state by colour alone: add an icon or a word.
