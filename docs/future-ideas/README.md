# Future ideas

Ideas for later. One file per idea, named `NN-short-name.md`. Nothing here is decided or promised.

The repo is public, so keep family names and personal detail out.

## How an idea becomes real

- A decision goes through `/adr-app-decide` and ends up in `docs/adr/`.
- A behaviour change goes into `docs/SPEC.md`.
- Then set the idea's status below to Built, or delete it.

## Statuses

- Idea: just a thought.
- Shaped: the problem and a rough design are written down.
- Planned: has a GitHub issue.
- Built: done, with a link to where.
- Dropped: decided against, with the reason.
